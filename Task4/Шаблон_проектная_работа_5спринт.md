| Роль                   | Права роли                                                                                                                                                     | Группы пользователей                                                                               |
| ---------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| platform-admin         | Полный доступ ко всем ресурсам и операциям кластера Kubernetes (включая управление RBAC, namespaces, workloads, secrets).                                      | grp-platform-admins (центральная platform/SRE команда).                                            |
| secrets-reader         | Привилегированный доступ только на чтение секретов (`get/list/watch` secrets) во всех namespaces.                                                              | grp-security-auditors (команда ИБ/аудита).                                                         |
| namespace-viewer       | Доступ только на чтение (`get/list/watch`) ресурсов приложений в рамках namespace: pods, services, deployments, jobs, ingresses и др. Без доступа к secrets.   | grp-payments-viewers, grp-logistics-viewers (разработчики продуктовых команд с правами просмотра). |
| namespace-configurator | Настройка ресурсов приложений в рамках namespace: создание/обновление/удаление deployments, services, configmaps, jobs, ingresses и др. Без доступа к secrets. | grp-payments-engineers, grp-logistics-engineers (DevOps/инженеры продуктовых команд).              |
